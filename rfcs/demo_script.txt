FIVE-MINUTE PRESENTATION
Person A -> Demo presenter -> Person A

0:00-2:00 — PERSON A: INTRODUCE THE PROJECT

“Every payroll cycle comes with an important responsibility: pay people accurately and on time. When a paycheck changes unexpectedly, payroll teams need to understand what changed, whether it is expected, and what needs attention before the payrun moves forward.

Today, that work can involve comparing records, investigating differences, documenting findings, and answering the same follow-up questions across multiple people. Each handoff can mean gathering the information again and explaining the background again.

AI Studio brings assistance into that workflow. The aim is to help payroll teams focus their attention, understand unusual payments, and carry the findings forward into a report and subsequent conversations.

Think of a payroll specialist reviewing a payrun. They can see which paychecks need attention, request an investigation, and review a brief explanation based on the available evidence. When an issue needs documenting, they can create a report from that investigation. If a colleague has another question, the chat assistant can use the existing findings and report as context.

The intended business value is less repeated information gathering, more consistent review and documentation, and easier access to the reasoning behind a flagged payment. The payroll specialist remains responsible for deciding whether a change is expected and what action to take.

For the organization, this also creates a reusable foundation. We start with Payroll, then apply the same approach to other workflows, with their own data connections and policies. Access controls, PII handling, and the choice of private or managed models support those different requirements.

In the next two minutes, we’ll show how these assistants are created and made available within Payroll, then follow the journey from identifying an unusual paycheck to investigating it, documenting it, and asking a follow-up question.”

4:00-5:00 — PERSON A: TIE THE DEMO BACK TO THE PPT

“What we just saw brings the platform story together.

The template-driven agent factory made agent creation repeatable. We configured each agent’s purpose, model, and access using the same foundation.

The access controls connected agents to the information they needed—both business APIs and context from other agents.

Inside Payroll, those pieces became a connected workflow: Jev detected paycheck anomalies, an explicit Review action triggered the LLM investigation, and the Incident Report agent turned that investigation context into a stored report. Chat then provided a way to ask follow-up questions using context from both agents.

This connects back to the presentation’s three themes: create agents faster, control their access to data, and choose where inference runs.

Payroll is our reference implementation. Extending to another domain requires its own integrations and policies, while reusing the agent factory, templates, permissions, and context-sharing foundation.”
